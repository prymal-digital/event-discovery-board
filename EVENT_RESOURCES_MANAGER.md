# Event Resources Manager — by city

**Last updated:** 2026-06-22
**Purpose:** Master list of every event source, organised per city. Each city lists what's pulled weekly, the backup venue pages, the local aggregators, and the cross-city platforms (with that city's own search URL) that are *not* pulled in the standard run.

## Legend

- **★ Pulled weekly** — part of the standard Monday scan (RA city page + recurring community sources).
- **◦ Backup venue page** — checked ad-hoc (Tier 3) only when the RA city page looks thin for that venue.
- **⚠ Not pulled — standing gap** — a cross-city platform the digest flags as uncovered each week (Meetup keyword sweeps, Eventbrite, Luma, Hipsy, Shotgun). Listed here per city so they can be swept on demand.

## 🔴 Mandatory every run — PRYMAL (multi-city)
